# Бот «комментарий -> личка -> проверка подписки -> файл»

Что делает: человек пишет в комментарии под постом ключевое слово (по умолчанию `fayl`), бот отвечает ему в личку с кнопкой «Obuna bo'ldim ✅». После нажатия бот проверяет через Instagram API, подписан ли человек (`is_user_follow_business`). Подписан: присылает ссылку на файл. Не подписан: просит подписаться и нажать кнопку ещё раз. Если проверка не удалась, файл не отдаётся.

Файлы: `core.mjs` (логика), `server.mjs` (сервер webhook, Node 18+, без зависимостей), `test.mjs` (тест на макете Instagram, `node bot/test.mjs`, 12 проверок проходят).

## Переменные окружения
| Имя | Что это |
|---|---|
| `IG_USER_ID` | ID вашего Instagram-аккаунта (показан в кабинете Meta) |
| `ACCESS_TOKEN` | токен доступа Instagram (секрет, в чат не писать) |
| `APP_SECRET` | секрет приложения Meta (проверка подписи webhook) |
| `VERIFY_TOKEN` | любое слово, которое вы сами придумаете и вставите в Meta и в сервер |
| `KEYWORDS` | ключевые слова через запятую, например `fayl,file,pdf` |
| `FILE_URL` | ссылка на файл, который получат подписчики |
| `GRAPH_BASE`, `GRAPH_VERSION` | по умолчанию `https://graph.instagram.com` и `v21.0` |

## Настройка в Meta (делаете вы; шаги по моей памяти, сверяйте с экраном)
1. Аккаунт `@mohiyat___` должен быть профессиональным (Business или Creator): Настройки, Тип аккаунта.
2. https://developers.facebook.com, My Apps, Create App, тип Business. Добавьте продукт Instagram, раздел «API setup with Instagram login».
3. Нажмите «Add account», войдите в Instagram и разрешите доступ. Нажмите «Generate token»: это `ACCESS_TOKEN`. Рядом виден `IG_USER_ID`. Токен живёт около 60 дней, его надо обновлять.
4. Разрешения: `instagram_business_basic`, `instagram_business_manage_comments`, `instagram_business_manage_messages`. Пока приложение в режиме разработки, бот работает с вашим собственным аккаунтом без проверки Meta.
5. `APP_SECRET`: App settings, Basic, «App secret».
6. Webhooks: Callback URL `https://ВАШ_ХОСТ/webhook`, Verify token = ваш `VERIFY_TOKEN`. Подпишитесь на поля `comments`, `messages` и `messaging_postbacks`. Включите переключатель подписки аккаунта на webhooks.

## Запуск
```
IG_USER_ID=... ACCESS_TOKEN=... APP_SECRET=... VERIFY_TOKEN=... FILE_URL=https://... KEYWORDS=fayl node bot/server.mjs
```
Серверу нужен публичный HTTPS-адрес, который работает постоянно (бесплатный хостинг: Render, Koyeb, Fly, либо Netlify или Floot с небольшой адаптацией). Локально и в облачной сессии он не работает: Instagram не достучится до временной машины.

## Что проверено, а что нет
- Проверено тестом на макете: проверка webhook, подпись, ключевое слово, один ответ на комментарий, выдача файла только подписанным, обработка ошибок, игнор эхо-сообщений.
- Не проверено на настоящем Instagram: сработает ли поле `is_user_follow_business` для этого аккаунта сразу после комментария, доставляются ли webhook комментариев в режиме разработки и допускает ли Instagram кнопку (quick reply) в приватном ответе. Это выяснится только при живом тесте; если кнопки нет, человек пишет слово `tayyor` (бот его тоже понимает).
- Ограничения Instagram: приватный ответ на комментарий можно отправить один раз и в течение 7 дней; дальше переписка идёт, пока человек отвечает (окно 24 часа).
