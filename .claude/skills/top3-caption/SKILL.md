# Описание в формате top3

Узбекский, латиница. Структура (по описанию ролика «Sigir», 28 тыс. просмотров):

1. **Первая строка** с вопросом-хуком + один эмодзи: «Nega Qur'onning eng uzun surasi «Sigir» deb ataladi? 🐄»
2. **2–3 предложения**: цифра-контраст и интрига без ответа.
3. **⏱ Videoda nima bor:** таймкоды `0:00 …` по блокам сценария (10–14 строк, по реальным секундам финального ролика).
4. **📌 Qisqacha:** 3–4 пункта «•» с проверенными фактами; объяснения как «olimlarning izohlaridan biri».
5. **💬 / 📤 / 🔔:** вопрос зрителю в комментарии, «yaqiningizga yuboring», обязательство подписаться (допустимо в этом формате).
6. **ℹ️ Оговорка:** «Bu tafsir emas, oddiy tushuntirish. Diniy savollar bo'yicha ishonchli mutaxassisga murojaat qiling.»
7. **Манба:** сура и номер оятов, «Muhammad Sodiq Muhammad Yusuf tarjimasi, alquran.cloud», тафсир (если использован), научный источник по числам.
8. **Хэштеги** (8–12): `#oddiymohiyat #o'zbekcha #quron` + тема (`#baqara #sigir`) + `#islom #bilasizmi #ilm`.

Сохранять в `reels/release/NN-caption.txt`. Таймкоды сверять с готовым роликом, не придумывать. Не обещать «mo'jiza/isbotlandi».
