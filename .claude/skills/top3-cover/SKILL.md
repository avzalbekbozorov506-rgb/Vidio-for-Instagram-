# Обложка в формате top3

Размер 1080x1920 (9:16), важное внутри безопасной зоны 1080x1350 по центру (профиль обрезает до 3:4).

## Раскладка сверху вниз
1. **Плашка-рубрика**, маленькая, капсом, жёлто-оранжевая: «QUR'ON SURASI», «ENG UZUN SURA», «QUR'ONDAGI IBORA».
2. **Заголовок-вопрос**, крупный, жирный капс, белый + один ключевой слог/слово жёлто-оранжевым: «NEGA SIGIR?», «NEGA SURA NOMI O'RGIMCHAK?!». Не больше 5–6 слов, не больше 3 строк.
3. **Один предмет-образ** по теме (корова, паутина, пчела), без людей и лиц; можно арабскую строку только если тема про буквы (палиндром).
4. **Цифра-контраст внизу**, мелко, капсом: «286 OYATDAN FAQAT 7», «69 OYATDAN FAQAT BITTASI». Если цифры нет, подпись-интрига («Bu tasodifmi?»).

## Цвет и шрифт
Фон: почти чёрный (#0b0b0f) или тёмно-синий с мягким светом; акцент жёлто-оранжевый (#ffb400); текст белый. Шрифты из `reels/public/fonts`: Anton (заголовок), Montserrat 800/600 (плашка и подпись), Amiri (арабская строка).

## Проверка
Читается в миниатюре 3 см (профиль): заголовок видно без зума; цифра правильная и совпадает с роликом; плашка не налезает на кнопку профиля. Сохранять в `reels/release/NN-cover.png`. Источник цифры указать в описании ролика.
