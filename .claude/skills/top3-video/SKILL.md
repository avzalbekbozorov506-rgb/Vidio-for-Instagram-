# Видео в формате top3 (Remotion, `reels/`)

Старые композиции удалены 15.11.2026 (в истории git). Новый ролик пишется заново в `reels/src/`.

## Порядок
1. **Вход:** утверждённый сценарий + файл озвучки от пользователя (OvozAI, wav/mp3) в `reels/public/vo-NN/`. Озвучку делает пользователь.
2. **Выравнивание слов:** `python3 -m venv /tmp/cfa-venv && /tmp/cfa-venv/bin/pip install ctc-forced-aligner unidecode`, затем выровнять озвучку по тексту, получить JSON слов с временем (скрипты конвейера удалены, при необходимости восстановить `align-words.py` и `make-voice-json.py` из истории git).
3. **Раскадровка по сценарию:** 1080x1920, 30 fps. Сцены: (а) 0–4 с заголовок-вопрос и цифра-контраст как на обложке top3, (б) предмет-образ с мягким движением камеры (зум 1.0–1.08), (в) блоки по смыслу, на каждые 10–12 с новая сцена или деталь, (г) финал: вывод и вопрос зрителю.
4. **Экран:** только субтитры-капсула по словам (подсветка текущего слова) и графика темы; без лиц, без пророков и сподвижников; арабский текст только если оят показывается по просьбе пользователя и тема про буквы.
5. **Звук:** озвучка пользователя + тихая музыка-подложка (−22 dB от голоса) и 2–4 мягких эффекта на смене сцен. Музыку и эффекты взять из бесплатных источников с лицензией и записать в `reels/public/`.
6. **Контроль:** 3–5 контрольных кадров (0 с, середина, финал), проверить читаемость субтитров в безопасной зоне, синхронизацию слов, длину 1:15–1:30.
7. **Рендер:** `npx remotion render <Id> out/NN.mp4` в `reels/out/`; mp4 в git не коммитить. Отправить пользователю через SendUserFile вместе с обложкой и описанием.
