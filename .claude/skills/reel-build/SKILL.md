# Сборка ролика (reel-build)

Рабочая папка `reels/`. Перед началом: `cd reels && npm install`, `echo ${AISHA_API_KEY:+set}`. Подробные правила: `/CLAUDE.md`, список роликов `reels/docs/INDEX.md`. Фокус с 10.11: религиозные темы (проверка по `CLAUDE.md`, раздел «Религия»).

## Шаги (не пропускать, порядок обязателен)

### 1. Тема и референс
- Берём тему из идей в `CLAUDE.md` или лучший формат по метрикам (`posts_list sort=views`, лидер: «Sigir», хук-парадокс с числом).
- Религия: аяты только с alquran.cloud (арабский Усмани + узбекский М. Содик М. Юсуф), факты по первоисточникам, спорное «Bir izohga ko'ra», без «isbotlandi/mo'jiza». Проверку делает пользователь.

### 2. Сценарий `scripts/script-NN.json`
- Ключи: `id,title,lang,voice,model,speed,hook,cover_text,status,rules,facts,cards[{n,vo,on_screen}]`; образец `scripts/script-41.json`.
- 60-70 с (≈13-14 симв./с, реально на 15-20% длиннее), хук ≤5 с с вопросом и «Javob oxirida», повторные хуки, ответ теми же словами.
- В `vo` нет цифр, двоеточий, кавычек, тире. Арифметику проверять кодом.
- САМОПРОВЕРКА до показа: грамматика узбекского, логическая цепочка, смысл и факты. Пользователю показать ТОЛЬКО сценарий (vo по карточкам) + одна строка о спорном на слух, 2-3 варианта первой фразы.

### 3. Озвучка (платно, только после «ок» пользователя; назвать цену ДО)
```
VOICELAB_MODEL=lison-v2 node scripts/tts-cards.mjs scripts/script-NN.json public/vo-NN voice_ba303813-3023-48aa-a454-4b5705669d35 1
python3 scripts/word-timing.py scripts/script-NN.json public/vo-NN     # без `| head` (ломает запись words.json)
```
- Склейка `full.mp3` (ffmpeg concat, пауза 0,25 с), отправить пользователю.
- Хук >5 с: `atempo=1.15` на `card-01.wav`, затем пересчитать `durations.json` и повторить word-timing.

### 4. Сборка композиции `src/<Name>.tsx` (образец `src/Kavsar.tsx`)
- Зарегистрировать `<Name>` и `<Name>Cover` в `src/Root.tsx`.
- События привязаны к `words.json` (`EV(n,i)`), одна крупная идея на карточку, деталь на смысловое слово, НИ ОДНОГО пустого экрана в начале карточки (опорный объект с 0,1-0,5 с), без плашки над субтитрами, безопасная зона x 80..960, y 250..1560, без изображения Пророков и сподвижников.
- Кинематограф: блоки `src/blocks/Cinematic.tsx` (`ParallaxLayer`, `Bokeh`, `Vignette`, `Grain`, `PopIn`, `KeyFlash`, `SlowPush`), чек-лист `reels/docs/CINEMATIC_2D.md`.
- Звук: `music/ambient.wav` 0.05, sfx ×0.6 на ключевых словах, голос главный.
- `npx tsc --noEmit` должен проходить.

### 5. Проверка ДО рендера (обязательна)
`./scripts/preview.sh <Id> vo-NN` (1-2 мин) -> смотреть `out/<Id>-preview/sheet-*.png`: пустые начала карточек, наложения, выход из безопасной зоны, мелкие элементы. Править и повторять, пока лист чистый.

### 6. Рендер
`./scripts/render-part.sh <Id> vo-NN out/x-raw.mp4 [карточки для перерендера]`. Кэш по карточкам в `out/parts/<Id>/`; при правке общих блоков или озвучки `rm -r out/parts/<Id>`. Альтернатива: `npx remotion render <Id> out/x-raw.mp4 --concurrency=4` (≈13-15 мин на 100 с; машина на 4 ядра, ускорить нельзя).

### 7. Мастеринг и проверка готового mp4
- `./scripts/master.sh out/x-raw.mp4 release/<name>-reel.mp4` (-16 LUFS).
- Кадры каждые 2,5 с: `ffmpeg -i f.mp4 -vf "fps=1/2.5,scale=216:384,tile=10x5" -frames:v 1 sheet.png`; смотреть глазами зрителя. `ffprobe`: 1080x1920, 30 fps, h264, yuv420p, aac.
- Что не проверено (например, звук на слух), назвать честно.

### 8. Обложка
- Композиция `<Name>Cover`: плашка-категория сверху, главный объект, название + вопрос, плашка снизу; зона y 270..1560, шрифт ≥42 px. `docs/COVER_GUIDE.md`.
- Вшить в первые 0,15 с: ffmpeg concat png + тишина, 1080x1920, 30 fps, `crf 23 maxrate 6M`; результат `release/<name>-reel-cover.mp4`. Удалить промежуточный `release/<name>-reel.mp4`.

### 9. Описание `release/<name>-caption.txt`
Хук, «⏱ Videoda nima bor» с таймингами (кодом из `durations.json`, +0,15 с обложка, +0,25 с паузы между карточками), краткое правило, 3 призыва (комментарий, переслать, обсудить/подписка), оговорка «Bu tafsir emas...», источники, 10-12 хэштегов (всегда `#oddiymohiyat #o'zbekcha`).

### 10. Публикация (только по просьбе пользователя)
- Закоммитить и запушить mp4, затем `fetch_asset` по raw-ссылке GitHub, `posts_create` со `scheduledAt` (+05:00), слоты Ташкента 09:00 / 13:00 / 20:00. connectionId `b46de7e7-b2f2-40e9-9a7d-fc4231e6d675`.
- Перед религиозным роликом напомнить про проверку (@dinuzbbot или юрист).
- На таймауте `posts_create` не повторять: смотреть `posts_list status=publishing`.
- После выхода: mp4 удалить из `release/` (`git rm`), png и txt оставить; обновить `docs/INDEX.md`.

### 11. Конец
Обновить блок «Состояние» в `CLAUDE.md`, `docs/INDEX.md`, закоммитить, запушить в ветку сессии; PR в `main` только по просьбе.
