# Vidio-for-Instagram-

Reels для Instagram @mohiyat___ («Oddiy mohiyat») в одном формате, который набрал 24–28 тыс. просмотров: вопрос-парадокс про суру Корана + цифра-контраст.

- `CLAUDE.md`: правила проекта (читать первым).
- `reels/docs/FORMAT_TOP3.md`: описание формата и данные по трём лучшим роликам.
- `.claude/skills/`: `top3-script` (сценарий), `top3-cover` (обложка), `top3-caption` (описание), `top3-video` (сборка и рендер).
- `reels/`: проект Remotion (каркас, шрифты `public/fonts`). Композиции, звуки, голоса и старые документы удалены 15.11.2026, они в истории git.
