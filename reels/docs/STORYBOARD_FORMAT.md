# Формат раскадровки (выход `avzalbot3`, вход для сборки в Remotion)

Режиссёр отдаёт:

1. Ответ в чат в формате из своей инструкции (A. концепция, B. раскадровка-таблица, C. AI-промпты, D. монтаж, E. обложка, F. проверка).
2. Файл `reels/storyboards/storyboard-NN.json` (тот же номер, что у сценария). Если записи нет, JSON блоком в ответе.

## Схема `storyboard-NN.json`

```json
{
  "id": "storyboard-03",
  "script": "script-03",
  "variant": "remotion",
  "concept": "главная визуальная идея одной фразой",
  "palette": {"bg": "#0d231c", "accent": "#d4a935", "text": "#f4f0e4", "paper": "#efe6d0"},
  "music": "bed.wav, тихо; где тише и где громче",
  "cards": [
    {
      "n": 1,
      "duration_s": 3.9,
      "vo": "точная фраза диктора из сценария",
      "subtitles": ["Pulingiz", "o'g'irlanmadi,", "lekin kamaydi."],
      "beats": [
        {"at_s": 0.0, "block": "Title", "props": {"lines": ["PULINGIZ", "KAMAYDI"]}, "camera": "zoom-in 1.0→1.08", "sfx": "low whoosh", "production": "remotion"},
        {"at_s": 1.8, "block": "Coin", "props": {"label": "100 000 so'm"}, "camera": "static", "sfx": "coin drop", "production": "remotion"}
      ],
      "transition_out": "match cut: монета → корзина",
      "ai_prompt": null
    }
  ],
  "cover": {"text": "...", "concept": "...", "ai_prompt": null},
  "checks": {"first_frame": 8, "retention": 8, "variety": 7, "sync": 9}
}
```

## Правила

- `duration_s` бери из `reels/public/vo-NN/durations.json`, если озвучка уже есть. Если её нет, оценка `1,2 + символы/18` с пометкой «оценка».
- `beats[].at_s` отсчитывается от начала карточки. Смена визуального акцента каждые 1–3 с.
- `subtitles`: фраза `vo`, порезанная на куски по 1–4 слова, в том же порядке, без изменений текста. Сборщик раскидает их по времени.
- `production`: `"remotion"` (бесплатно, сразу) или `"ai"` (платная генерация, только если пользователь утвердил бюджет). Для варианта `"remotion"` все beats должны быть `remotion`.
- Если предлагаешь «Премиум AI-версию», делай её отдельным файлом `storyboard-NN-ai.json` с `ai_prompt` (на английском, 9:16, с continuity) для каждой AI-сцены.

## Безопасные зоны кадра 1080×1920

- Верх 0–220 px: статус-бар и подписи Instagram, не ставить важное.
- Низ 1540–1920 px: описание, ник, кнопки. Субтитры держать в полосе y ≈ 1250–1500.
- Правый край 960–1080 px: кнопки лайк/коммент/отправить, не ставить текст.
- Центр 80–960 по x и 220–1500 по y: главное.

## Каталог готовых блоков Remotion (реализованы в `src/Turkic.tsx` и `src/Atlas.tsx`)

| Блок | Что делает | Основные props |
|---|---|---|
| `BaseMap` | Карта мира (Natural Earth), подсветка стран цветом, «камера» lon/lat/zoom, затемнение | `fills`, `camera`, `dim` |
| `Header` | Маленькая подпись + крупная золотая цифра со счётчиком | `label`, `target`, `decimals`, `prefix`, `unit` или `value` |
| `Title` | 1–3 строки крупного заголовка (белый и золотой), pop-in | `lines[{t,color}]`, `size`, `top` |
| `Tag` | Бумажный ярлык с рваным краем, опционально линия-указатель на точку | `x`, `y`, `text`, `sub`, `lineTo` |
| `Panel` | Кремовая карточка снизу для сравнений | children |
| `BarRow` | Горизонтальная шкала с подписью и значением, анимация роста | `label`, `text`, `ratio`, `color` |
| Stacked bar | Доли в одной полосе (как «Turkiya ≈ 77%») | внутри `Panel` |
| `Coin` | Золотая монета с надписью, переворот при появлении | `name`, `sub` |
| `Clock` | Аналоговые часы, стрелка доворачивается | `hour`, `city` |
| Route | Анимированная линия маршрута по карте | точки lon/lat |
| Glow dots | Светящиеся точки на карте | точки lon/lat |
| `Logo` | Круг «OM» внизу справа | — |
| Scrim | Тёмный градиент сверху и снизу для читаемости | встроен в `BaseMap` |

**Пока НЕТ, но делается за один проход сборки (заказывай смело, отметь «новый блок»):** субтитры (обязательны), счётчик-ценник, корзина и товары (иконки SVG), график линией, «весы», человечки (stick figures) в стиле `@bayon.life`, календарь, банковская карта и экран телефона (без брендов), разрыв купюры, падающие монеты (SVG, без фотореализма).

**Не делается в Remotion:** фотореализм, 3D, живые люди, реальная съёмка. Это только вариант `"ai"`.
