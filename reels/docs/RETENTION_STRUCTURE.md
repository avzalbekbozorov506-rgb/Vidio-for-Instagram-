# Структура ролика «чтобы досматривали» (2026-11-09)

Проблема: ролики 80-120 с, мало досмотров, у аккаунта почти нет подписчиков (решает пробная группа показа). Цель: 55-70 с.

## Таймлайн (60-65 с)
| Время | Блок | Правило |
|---|---|---|
| 0-3 с | **Хук** | Парадокс/вопрос, без вступлений («Keling...» нельзя). Голос с первого кадра. |
| 3-7 с | **Обещание** | «Oxirigacha ko'ring, eng oddiy yechim oxirida.» Открытая петля. |
| 7-50 с | **Тело** 4-5 шагов | Каждый шаг 7-10 с: «Lekin [беда]. Shuning uchun [деталь]. Bu [термин].» Смена картинки каждые 3-5 с. Микро-интрига в конце шага. |
| 50-58 с | **Развязка** | Ответ на хук теми же словами («Demak, ...»). |
| 58-65 с | **Призыв** | Одна просьба (переслать), не дольше 6 с. |

## Правила
1. Макс. длина 70 с. Один вопрос — один ответ. Каждая карточка до ~130 символов.
2. Первые 0,15 с — обложка (не 0,5 с), голос стартует сразу.
3. Нет пауз длиннее 0,25 с между карточками. Вода/факты без повторов.
4. Конец зеркалит хук (петля). Обещание из начала выполнено.
5. Метрики проверять: средняя длительность просмотра и график удержания (Instagram Insights, скриншот от пользователя), пересылки/показы.
