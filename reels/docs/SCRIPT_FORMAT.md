# Формат сценария (выход `avzalbot2`, вход для озвучки и `avzalbot3`)

Сценарист отдаёт ДВЕ вещи:

1. Ответ в чат в формате из своей инструкции (разделы 1–7: название, хук, сценарий для озвучки, финальная фраза, текст обложки, описание Instagram, оценка) и раздел **9. ТЕХНИЧЕСКОЕ**.
2. Файл `reels/scripts/script-NN.json` (NN = следующий свободный номер). Если у агента нет права записи, он выдаёт JSON блоком в ответе, а оркестратор сохраняет его.

## Схема `script-NN.json`

```json
{
  "id": "script-03",
  "title": "Pul sandiqda yotsa",
  "lang": "uz-Latn",
  "voice": "Amir",
  "target_seconds": 45,
  "hook": "Pulingiz o'g'irlanmadi, lekin kamaydi.",
  "final_line": "...",
  "cover_text": "SANDIQDAGI PUL KAMAYADIMI?",
  "caption": "...описание Instagram с дисклеймером и хэштегами...",
  "cards": [
    {"n": 1, "role": "hook", "vo": "текст диктора словами", "on_screen": "короткий текст/цифра на экран", "visual_hint": "идея картинки одной фразой"},
    {"n": 2, "role": "gap", "vo": "...", "on_screen": "...", "visual_hint": "..."}
  ],
  "facts": [
    {"claim": "что утверждаем", "source": "название источника", "url": "https://...", "status": "проверено | не проверено"}
  ],
  "totals": {"chars": 640, "est_seconds": 45.2, "credits": 640},
  "self_score": {"hook": 8, "retention": 8, "emotion": 7, "share": 7, "language": 9, "recognition": 8, "pain": 8, "solution": 8},
  "skip_test": [{"card": 3, "risk": "почему может уйти", "fix": "что сделано"}]
}
```

## Правила полей

- `cards[].n` подряд с 1. Именно поле `vo` уходит в озвучку, файл `card-NN.wav` соответствует `n`.
- `role`: `pain`, `recognition`, `question`, `story`, `answer`, `solution`, `share` (старые `hook`, `gap`, `twist`, `payoff` тоже допустимы).
- `vo`: только то, что говорит диктор. Без ремарок, без цифр и знаков (смотри `UZBEK_TTS_STYLE.md`).
- `on_screen`: 1–6 слов или одна цифра. Именно здесь точные числа.
- `visual_hint`: подсказка режиссёру, не обязательна к исполнению.
- `totals.chars` = сумма длин всех `vo` (символы, включая пробелы и знаки). `est_seconds` = сумма по карточкам `1,2 + символы/18`.
- `facts`: каждое числовое или историческое утверждение. Если источник не найден, пометь `"не проверено"` и не делай на нём главный вывод.

Пример старого формата (до этой схемы): `reels/scripts/script-02.json` (поля `n`, `screen`, `vo`). Новая схема обратно совместима: скрипт озвучки читает только `n` и `vo`.
