# Формат описания ролика (с 12.11.2026)
Файл `release/<id>-caption.txt`. Instagram скрывает всё после первых 2 строк, поэтому порядок такой:

1. Хук, 1-2 строки: ключевое слово темы + обещание ответа. Без «oxirigacha ko'ring» в конце длинной фразы.
2. `⏱ Videoda nima bor:` тайминги считать кодом из `durations.json` (+0,15 с обложка, +0,25 с паузы), 6-9 строк, лишние промежуточные опускать.
3. Три призыва, каждый одной строкой:
   - `💬` вопрос зрителю (комментарий)
   - `📩` кому отправить (главный сигнал для охвата)
   - `🔖` сохранить и подписаться, одним предложением ценности канала
4. `📖 Manba:` источник (сура:аят или сборник и номер хадиса), «mazmun qisqartirib berildi», отсылка к ulamolarga, пометка «bir izohga ko'ra» для толкований, «Videodagi rasmlar xayoliy».
5. Хэштеги 6-8, всегда `#oddiymohiyat #o'zbekcha`, остальные по теме.

Не использовать: слова «mo'jiza», «isbotlandi», «taqiqi».
