# Как писать узбекский текст для озвучки (голос VoiceLab)

Для `avzalbot2`. Текст пишется для УХА, а не для глаза. То, что красиво на экране, может плохо звучать.

## Орфография (латиница)

- **Только латиница** (решение пользователя: голос принимает латиницу). Кириллицу не используем вообще, даже если инструкция просит.
- Буквы `o'` и `g'` пишем через обычный апостроф `'` (так озвучены все прошлые ролики). Не смешивать в одном тексте `'`, `ʻ`, `’`.
- Тутуқ белгиси (знак разделения, например `ma'no`, `san'at`) тоже `'`.
- `sh`, `ch`, `ng` пишутся как есть.
- Перед выдачей проверь: падежи, окончания, порядок слов (глагол в конце), согласование. Никаких калек с русского («bu narsa bo'ladi qilish»).

## Цифры и знаки в тексте диктора

Пока произношение цифр НЕ проверено, действует осторожное правило:

- **В поле `vo` (что говорит диктор) числа пиши словами**, и по возможности круглые и простые: «qariyb ikki baravar», «yuz ming so'm», «o'n yil ichida». Точные числа («4,2 mln km²», «12 %») ставь в поле `on_screen` (на экран).
- Не пиши в `vo` знаки `$`, `%`, `№`, `km²`, `:`: говори словами («dollar», «foiz»).
- Не пиши в `vo` аббревиатуры (XVF, YAIM, BMT, AQSh): говори полностью или перефразируй («Xalqaro valyuta jamg'armasi», «davlat statistikasi»). Аббревиатура уместна только на экране.
- Даты словами, если они важны на слух: «ming to'qqiz yuz to'qson birinchi yilda». Если дата не важна, лучше «o'ttiz yil oldin».
- Деньги: «so'm», «dollar» словами. Суммы округляй.

## Ритм и интонация

- Одна карточка = одна мысль, 40–120 символов. Короткие предложения по 6–12 слов.
- Хук это короткое утверждение или короткий вопрос. Вопросительная интонация голоса не проверена, поэтому сильнее работает утверждение-парадокс («Pulingiz o'g'irlanmadi, lekin kamaydi.») или вопрос, у которого ответ очевидно интересен.
- Избегай длинных цепочек «va ... va ... va». Лучше два предложения.
- Иностранные имена и названия пиши так, как их произносит узбек (Shveytsariya, Germaniya). Сложных слов, которые голос может исказить, избегай или проверь.
- Обращение к зрителю на «siz» (вежливо), живо, без канцелярита.

## Структура по карточкам (подробно в `PAIN_FORMULA.md`, она главнее)

БОЛЬ (1) → узнавание (2) → ВОПРОС (2–3) → развитие с мини-крючками → ОТВЕТ (суть) → РЕШЕНИЕ (1–3 шага) → финал с адресатом.

Старая схема для справки:

1. Карточка 1: HOOK (1–3 с) — парадокс или боль зрителя.
2. Карточка 2: CURIOSITY GAP — загадка, которую раскроем в конце.
3. Карточки 3..N-2: STORY — простой пример из жизни (базар, зарплата, рассрочка, сундук с деньгами).
4. Карточка N-1: PATTERN INTERRUPT + PAYOFF — неожиданный ответ.
5. Карточка N: SHARE TRIGGER — мысль, которую хочется отправить конкретному человеку (маме, другу, который берёт кредит). Без «отправь 10 друзьям».

## Описание Instagram и экранный текст

- **Хэштеги без апострофа**: Instagram обрезает хэштег на апострофе (`#o'zbekcha` превращается в `#o`). Пиши `#ozbekcha`, `#ozbekiston`. Базовый набор: `#oddiymohiyat #ozbekcha #pul #iqtisod` + 2–4 по теме.
- **В `on_screen` только буквы, цифры и обычные знаки** (`. , : % - ≈`). Не используй `✓`, `→`, `✗`, эмодзи: в наших шрифтах (Anton, Montserrat) их может не быть. Стрелки и галочки рисует режиссёр фигурами.
- Слова «o'tgan yili», «bu yil» привязаны к дате выхода. Если факт за конкретный год, на экране пиши год («2025»), в `vo` можно «o'tgan yili» только если ролик выйдет в следующем году.

## Самопроверка перед выдачей

- [ ] Сумма символов `vo` укладывается в бюджет длины (`PIPELINE.md`, раздел 3).
- [ ] В `vo` нет цифр, знаков, аббревиатур (кроме осознанных исключений, помеченных для проверки).
- [ ] Каждый факт имеет источник со ссылкой.
- [ ] Нет религии, политики, медицинских и юридических советов, обещаний дохода; для денежных тем дисклеймер в описании.
- [ ] Научные и психологические факты не из списка мифов (`PIPELINE.md`, раздел 8), с автором и годом.
- [ ] Хэштеги без апострофов, в `on_screen` нет ✓ → и эмодзи.
- [ ] Текст прочитан вслух мысленно: нет мест, где диктор «споткнётся».
