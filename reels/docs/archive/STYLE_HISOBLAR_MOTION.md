# Стиль «Hisoblar» (референс пользователя, разбор движения, 2026-11-10)
Присланный ролик (90 с, 720x1280, «Hisoblar ko'rdik #16»). Берём приёмы движения и визуальный язык; тема, текст, голос, предметы свои.

## Камера
1. **Наезд/отъезд как раскрытие.** Камера держится на предмете (пачка 20), открывается крышка, выскакивает один предмет с выноской. Затем отъезд: предмет размножается в тысячи, камера уходит назад, и видна стена/колонна. Масштаб = смысл (один -> тысячи).
2. **Наклон камеры.** Предмет стоит прямо, камера идёт вниз, предмет «ложится» на календарь/поверхность (перспектива меняется за 1-1,5 с). Поверхность с перспективой уезжает вниз и размыта (глубина резкости).
3. **Плоские сцены с медленным дрейфом.** Графики и сетки: лёгкий наклон плоскости (rotateX ~50-60°), камера медленно сдвигается, без тряски.
4. **Сцена - это одно большое событие** + HUD сверху постоянный (серия, номер главы 01/07, название главы).

## Появление объектов
1. **Из тёмного:** fade + лёгкий подъём + рост света (свет по краям, как при выходе из тени).
2. **Пружина с лёгким перелётом** для предметов и плашек.
3. **Выноска на лидер-линии** («20» с линией к сигарете) появляется после объекта.
4. **Размножение:** клонирование сеткой, волной от центра; отъезд камеры прячет границы.
5. **Превращение материи:** масса предметов рассыпается в пиксельную пыль и собирается в другой предмет (ключ), позади вырастает силуэт города. (У нас: золотая пыль `KavsarDust.tsx` уже делает то же.)
6. **Контур-рисование:** контур карты рисуется светящейся линией, потом заполняется значками (иконки сеткой), счётчик «1/5» щёлкает цифрами как рулетка.
7. **Счётчик-рулетка:** цифры прокручиваются вертикально, затем встают; число «подрастает» (24 000 -> 4 824 000 -> 263 млн) с акцентом цвета.
8. **Круговой таймер:** кольцо заполняется сегментами оранжевым по времени слова («7 soat»), сверху счётчик с «=», затем размножение в ряд мини-таймеров.
9. **Сетка плиток в перспективе:** плитки появляются волной построчно, затем заливаются цветом (зелёный = «вернулось/осталось») по словам; рамка-выделение движется по сетке.
10. **Графики:** оси рисуются, кривая растёт линией с заливкой, вторая кривая (сравнение) пунктиром, ключевая точка пульсирует.

## Типографика и субтитры
- Крупное число оранжевым, единица мелко рядом. Ключевое слово заголовка курсивом с засечками (Cormorant italic) акцентным цветом.
- Субтитры мелкие снизу по центру, активное слово акцентным цветом, одна строка; под ними мелкий ник серым.
- Верхняя HUD-полоса: точка-логотип, название серии, «03/07 · 2-SINOV · 30 YIL», тонкая линия прогресса.

## Цвет и свет
Тёмный коричнево-янтарный фон, оранжевый акцент, зелёный только для решения/пользы, виньетка, мягкое боке, тёплый контровой свет, плёночное зерно. Один цвет на смысл.

## Как делаем у нас (Remotion)
- 2.5D: CSS 3D (`perspective`, `rotateX`) для плоскостей и сеток, SVG для графиков и контуров, canvas для частиц (как `KavsarDust`), `Cinematic.tsx` для боке/зерна/виньетки.
- Объёмные предметы: градиенты + грани через CSS 3D box (псевдо-3D); настоящий 3D (Three.js) только по необходимости (рендер 20-25 мин).
- Камера = общая обёртка (translate/scale/rotateX) с плавной кривой на события по словам.
- Проба на 10 с: HUD + предмет + размножение + отъезд + счётчик-рулетка + сетка плиток.
