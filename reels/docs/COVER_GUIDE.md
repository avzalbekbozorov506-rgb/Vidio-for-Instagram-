# Как делать кликбейтную обложку (изучено 2026-11-09, источники: статьи 1of10, thumbfa.st, predis, lilachbullock, podcastle; это практики авторов, не исследования)
1. **Разрыв любопытства:** показать достаточно, чтобы понять тему, и спрятать главное (ответ). Обложка ставит ВОПРОС, видео отвечает. Честность: видео обязано дать ответ, иначе падает досмотр.
2. **Конфликт/контраст на картинке с первого взгляда:** «до/после», «1 против 1 000 000», «неправильно ✗ / правильно ?». Зритель должен ЧТО-ТО УВИДЕТЬ (противоречие, шок-число, зачёркнутое), а не прочитать описание темы.
3. **Эмоция:** лицо с сильной эмоцией (+30-40% по блогам, не проверено); у нас лиц нет, замена: красный/жёлтый акцент-«тревога», ✗, «?!», стрелка на загадку.
4. **Мало слов: 3-5, один вопрос или шок-число**, жирный контрастный шрифт, читается за 1 с на маленьком экране; один главный объект.
5. **Один акцент-цвет + один резко контрастный цвет для «шока»** (красный ✗ на тёмном/синем).
6. **Обрезка сетки профиля 1:1:** главное по центру.
7. Единый стиль канала, но каждая обложка про ОДНО противоречие.
Проверка перед отдачей: за 1 секунду видно (а) о чём, (б) что-то странное/неожиданное, (в) вопрос, ответ на который хочется узнать.
