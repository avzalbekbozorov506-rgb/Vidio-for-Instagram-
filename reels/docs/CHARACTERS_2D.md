# 2D-герои для роликов (Person2D)

Файл: `src/rig/Person2D.tsx`. Лист для просмотра: композиция `PeopleSheet`, анимация: `PeopleDemo`.
Герои без лиц (правило канала), вид спереди, общий скелет: шея, плечи, локти, бёдра, дыхание, покачивание, ходьба, сидение, позы.

## Герои (`who`)
| id | кто | отличительное |
|---|---|---|
| `yigit` | молодой мужчина | дóппи, бирюзовая рубашка, тёмные брюки |
| `chol` | старик | белая борода, чалма, длинный чапан с кушаком, белые штаны |
| `qiz` | девушка | тёмный хиджаб, бежевая толстовка, длинная юбка (как в RainDua) |
| `ona` | женщина | длинное бордовое платье, белый платок |
| `bola` | мальчик | дóппи, жёлтая рубашка, масштаб 0,64, голова крупнее |

## Использование (внутри `<svg width=1080 height=1920>`)
```tsx
import {Person2D} from './rig/Person2D';
<Person2D who="chol" x={540} y={1500} s={1.2} pose="pray" t={t} />
// плавный переход между позами: pose="stand" to="pray" k={0..1}
// ходьба: pose={{walk: t * 7.5}} (фаза в радианах), flip зеркалит
```
Начало координат: центр стоп. Рост взрослого около 540 px при `s=1`, ставьте `y` на линию земли.

## Позы (`POSES`)
`stand`, `pray`, `prayUp` (голова вверх), `raise` (правая рука вверх), `hands`, `point`, `wide`, `worry`, `sit` (сидит), `sitPray`, `walk`.
Своя поза: `{lean, head, headX, aL: [подъём руки°, сгиб локтя°], aR: [...], sit: 0..1, walk}` (угол 0 = рука вниз, 90 = в сторону, 180 = вверх; сгиб локтя внутрь).

## Ограничения
- Вид только спереди; профиль не поддерживается (ходьба идёт «лицом к зрителю» с чередованием ног).
- Сидят скрестив ноги (без стула). Предметы в руках не встроены, рисуются отдельно у кисти.
- Лиц и мимики нет специально: пророков и Сподвижников не изображаем, это обычные люди.
