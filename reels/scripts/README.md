# Инструменты (reels/scripts)
Сценарии `script-NN.json`: тексты по карточкам (`cards[].vo`, `on_screen`, `visual_hint`). Ниже только программы.

## Сборка ролика
| Файл | Что делает |
|---|---|
| `make-reel.sh <Id> vo-NN <имя>` | Устойчивая сборка с озвучкой: рендер по карточкам с кэшем, возобновляется после обрыва |
| `render-part.sh` | Рендер выбранных карточек с кэшем (`out/parts`) |
| `preview.sh <Id> vo-NN` | Быстрые кадры до полного рендера (с безопасной зоной) |
| `make-silent.sh <Id> <имя>` | Ролик без озвучки: рендер, мастеринг, вшивание обложки |
| `master.sh in.mp4 out.mp4` | Громкость (по умолчанию -16 LUFS; `LUFS=22` для тихих роликов без голоса) |
| `watch-reel.sh` | Сторож долгой сборки |

## Озвучка и тайминги
| Файл | Что делает |
|---|---|
| `tts-cards.mjs` | Озвучка карточек сценария через VoiceLab (ключ в `AISHA_API_KEY`), платно |
| `tts.mjs` | Одиночная озвучка текста |
| `word-timing.py` | Метки слов по реальному звуку (паузы через `silencedetect`, слова по слогам) |
| `word-timing-fw.py` | Эксперимент: метки через faster-whisper; на тесте не лучше, не используется |
| `fake-timing.py` | Условные тайминги для роликов без озвучки |
| `syllables.mjs` | Счёт слогов в узбекской латинице |
| `pacing.py` | Темп смены картинки в готовом ролике |

## Источники и тексты
| Файл | Что делает |
|---|---|
| `tafsir.mjs 18:1 [ashur|kathir|kathir-en|maarif|qurtubi|tabari|uz]` | Тафсиры по ояту (spa5k/tafsir_api) |

## Звук и графика (генерация кодом, без чужих прав)
| Файл | Что делает |
|---|---|
| `make-oriental-music.py` | Восточная музыка (уд, ней, даф): `public/music/oriental.wav` (используется в квизах) |
| `make-calm-music.py` / `make-calm-music2.py` | Тихая музыка: `calm.wav` (Yaxshilik), `calm2.wav` (пианино) |
| `ambient.py`, `sfx.py`, `thunder.py` | Фоновая музыка и эффекты старых роликов |
| `glitter.py` | Облака точек «золотой пыли» для ролика Gold |
| `make-paper.py` | Текстура бумаги `public/img/paper.png` |
