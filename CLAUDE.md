## Озвучка (СТАРОЕ, не использовать: Voicelab.uz = Aisha)
Пользователь купил тариф Starter на voicelab.uz (60 000 UZS/мес, 60 000 кредитов, около 1 часа текста в речь). Ключ API создан, его пользователь кладёт в переменную среды `AISHA_API_KEY` (email не нужен). Старые `ZVUKOGRAM_*` не использовать.
- Base URL: `https://back.aisha.group`. Документация: https://aisha.group/en/api-documentation/text-to-speech
- `POST /api/v1/tts/post/`, заголовок `X-Api-Key: <ключ>`, поля формы (multipart): `transcript` (макс. 1000 символов), `language=uz`, `model=Gulnoza`, `mood` (Neutral, Cheerful, Happy, Sad), `speed` (0 или 0.5–2.0).
- Ответ JSON: `{"audio_path": "/media/tts_audios/<id>.wav"}` (полный URL аудио и хост выдачи в документации не указаны, проверить). Mp3 нет, только wav. Ошибки: 401 ключ, 402 баланс, 503 временно.
- Единственный известный узбекский голос: Gulnoza (женский). Список других голосов в документации отсутствует.
- Скрипт-заготовка: `reels/scripts/tts.mjs` (НЕ ТЕСТИРОВАН). Делит текст на куски ≤1000 символов.
- Первое дело в новой сессии: `echo ${AISHA_API_KEY:+set}`, затем тест на 50–100 символов, послушать/проверить и подключить к Remotion.

## Ограничения и правила
- Ключи в чат и в репозиторий не писать. `request_credential` пользователь один раз отклонил, повторно не предлагать без запроса.
- Среда «Узбекский Рилсы»: сеть без ограничений, переменные среды подхватываются только при старте сессии.
- Публикация через ShapelessAI (`posts_create`, пост ждёт одобрения) только по прямой просьбе. vidIQ публикация недоступна (токен неактивен).
- Remotion делает графику, текст, инфографику, субтитры; видео проверять по отдельным кадрам (`npx remotion still`), финальный просмотр за пользователем.
