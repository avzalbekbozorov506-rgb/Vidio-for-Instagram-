## Конвейер
1. Тема -> сценарий `scripts/script-NN.json` (`cards[].vo`, `on_screen`, `visual_hint`, `caption`), проверка знаков, фактов, арифметики.
2. «Ок» -> озвучка: `VOICELAB_MODEL=lison-v2 node scripts/tts-cards.mjs scripts/script-NN.json public/vo-NN voice_ba303813-3023-48aa-a454-4b5705669d35 1`; затем `python3 scripts/word-timing.py scripts/script-NN.json public/vo-NN`; склейка `full.mp3` (ffmpeg concat, пауза 0,25 с), показать пользователю. Хук >5 с сжать ffmpeg (`silenceremove` + `atempo` 1.15).
3. Сборка композиции в `src/` (события через время слов), регистрация в `Root.tsx`. Музыка тихо (`beat.wav` 0.06 / `ambient.wav` 0.1), sfx ×0.7.
4. Рендер: 2D `npx remotion render <Id> out/x-raw.mp4 --concurrency=4` (1,5-5 мин); 3D добавить `--gl=swangle` (20-25 мин).
5. `./scripts/master.sh out/x-raw.mp4 release/x-reel.mp4` (-16 LUFS), проверка кадров, вшить обложку, просмотр глазами.
6. Публикация только по просьбе: `fetch_asset` по raw-ссылке GitHub на запушенный файл, `posts_create` с `scheduledAt` (+05:00) и длинным описанием. Старый пост отменять `posts_dismiss`.

## Уроки
- `posts_create` на таймауте может создать пост с задержкой: смотреть `posts_list status=publishing` / `posts_get`, не повторять (или тот же `idempotencyKey`).
- Осторожно с regex-правками файлов с повторяющимися блоками.
- Метрики запаздывают на 1-3 ч. Лучший по просмотрам пост вышел вечером (20:19). Длинные ролики (100+ с) хуже досматриваются.
- Озвучка Jasur ≈ 13-14 символов/с; реальная длительность на 15-20% больше оценки.
- Шрифты Google в Remotion не грузятся (прокси), все шрифты в `reels/public/fonts`.
