## >>> КАК ДЕЛАЕМ РОЛИК (читать первым) <<<
Пользователь в новой сессии называет тему (или просит выбрать самому). Дальше конвейер:
1. **Сценарий**: запусти субагента `avzalbot2` (`.claude/agents/avzalbot2.md`) с темой. Он читает `reels/docs/*`, пишет по формуле БОЛЬ → ОДИН ВОПРОС → ОТВЕТ И РЕШЕНИЕ (`reels/docs/PAIN_FORMULA.md`), проверяет факты, сохраняет `reels/scripts/script-NN.json`.
2. **Проверка оркестратором**: пересчитать символы, нет цифр/знаков/кириллицы в `vo`, хэштеги без апострофов, факты со ссылками. Показать сценарий пользователю.
3. **«Ок» пользователя ОБЯЗАТЕЛЬНО до озвучки** (озвучка платная: 1 символ = 1 кредит VoiceLab).
4. **Озвучка**: `cd reels && node scripts/tts-cards.mjs scripts/script-NN.json public/vo-NN` (голос Amir, ключ в `AISHA_API_KEY`). Получаем `card-NN.wav` (тишина обрезана) и `durations.json`. Дать пользователю послушать.
5. **Раскадровка**: субагент `avzalbot3` (`.claude/agents/avzalbot3.md`) по сценарию и реальным длительностям → `reels/storyboards/storyboard-NN.json`. Только 2D в Remotion, без AI-генерации.
6. **Сборка**: оркестратор делает композицию в `reels/src/` (пример `Turkic.tsx`, блоки `Atlas.tsx`, `blocks/Subtitles.tsx`; новые блоки из раскадровки класть в `src/blocks/` для переиспользования), субтитры обязательны, пауза между карточками 0,12 с, музыка `public/music/bed.wav` тихо, обложка (`Cover.tsx`) первым кадром. Проверка кадров `npx remotion still`, рендер `npx remotion render`.
7. **Показать пользователю** видео, обложку, описание. После одобрения: публикация через ShapelessAI (видео в `reels/release/`, push, `fetch_asset` по raw-ссылке GitHub, `posts_create` без `scheduledAt` публикует СРАЗУ).
8. Записать итог в «Журнал сессий», закоммитить, напомнить про слияние в `main`.

Готовые сценарии на очереди: `script-05` (базар, эффект якоря, 636 симв., лучший), `script-03` (сундук и инфляция, 625 симв., есть раскадровка `storyboard-03`), `script-04` (algoritm, запасной, без формулы боли). Ни один ещё не озвучен.

**В конце сессии (или после каждого крупного шага):**
1. Обновить «Журнал сессий» ниже: что сделано, что решено, что дальше, где остановились.
2. Закоммитить и запушить в рабочую ветку сессии. PR в `main` создавать и сливать только по просьбе пользователя, и напомнить ему слить, если в `main` ещё нет свежих изменений.
