Язык общения с пользователем: русский. Контент и озвучка: узбекский (латиница `sh ch o' g'`).
Основная ветка `main`. Новая сессия работает в своей ветке, в конце просит пользователя слить её в `main` (PR только по просьбе). Секреты в файлы не писать.

## Главное решение (15.11.2026)
Репозиторий очищен, ролики делаем ТОЛЬКО в формате трёх лучших роликов профиля: «Nega SIGIR?» (28,4 тыс), «Boshidan ham, oxiridan ham bir xil» (26,2 тыс), «Nega sura nomi O'RGIMCHAK?!» (23,9 тыс). Описание формата: `reels/docs/FORMAT_TOP3.md`.

## Скилы (`.claude/skills`), порядок работы
1. `top3-script`: тема, факты, сценарий и текст для OvozAI (`reels/scripts/script-NN-ovozai.txt`). Пользователю показывать только готовый текст.
2. Озвучку делает пользователь в OvozAI (бесплатно) и присылает файл. VoiceLab (платный) только по просьбе, цену назвать до запуска.
3. `top3-video`: выравнивание слов, сборка и рендер кодом (Remotion, `reels/`).
4. `top3-cover`: обложка. `top3-caption`: описание.
5. Файлы пользователю отправлять через SendUserFile (mp4, png, txt); mp4 в git не коммитить.
