# Reels для Instagram (@mohiyat___, «Oddiy mohiyat»)

Язык общения с пользователем: русский. Контент и озвучка: узбекский (латиница `sh ch o' g'`).
Основная ветка `main`. Новая сессия работает в своей ветке, в конце просит пользователя слить её в `main` (PR только по просьбе). Секреты в файлы не писать.

## Главные документы (читать в начале сессии)
- `reels/docs/SCRIPT_STANDARD.md`: как писать сценарий (хук в 3 с, петля, деталь, вершина, финал-эхо, без оята, без призыва подписки и без «отправь другу»).
- `reels/docs/STYLE_PASSPORT.md`: единый стиль v3 «Qongiroq», конвейер, звук, синхронизация, бюджет времени.
- `reels/docs/CAPTION_FORMAT.md`, `reels/docs/COVER_GUIDE.md`: описание и обложка. `reels/docs/STYLE_BASHAR.md`: разбор референса.

## Порядок работы
1. Сценарий по `SCRIPT_STANDARD.md`: сам проверяю (грамматика узбекского, логика, факты), затем агент `avzalbot2` (сценарист-редактор, переобучен 15.11 под стандарт), пользователю показываю только готовый текст по карточкам.
1а. После утверждения текста: агент `avzalbot3` (режиссёр 2D-раскадровки по паспорту v3) даёт раскадровку `scripts/storyboard-NN.md`; код пишу я.
2. Единый текст с тегами для OvozAI (`scripts/script-NN-ovozai.txt`): пользователь озвучивает сам и присылает файл.
3. Очистка звука, выравнивание слов (`scripts/align-words.py`), `scripts/make-voice-json.py`, сцены и композиция по `STYLE_PASSPORT.md`, контрольные кадры, рендер `scripts/render-chunks.sh`, `scripts/master.sh`, обложка, описание.
4. Файлы пользователю отправлять через SendUserFile (mp4, png, txt); mp4 в git не коммитить.
